## 一、原则：MVP 不追求 100% 像素还原

| 误区 | 现实 |
|------|------|
| 必须蓝湖插件一键生成 Flutter | 生成代码常需 70%+ 手改，且无权限时无法使用 |
| 每个页面逐像素对齐 | 独立开发者时间成本极高，阻塞 P0 SOS 闭环 |
| 没有 Figma 就无法做 | 蓝湖导出资产 + 标注表同样可行 |

**P0 优先级**：SOS 按钮、SOS 状态页、地图相关页 > 个人中心美化 > 全站视觉统一。

## 二、向设计人员索取的「开发包」

把下面清单发给设计（飞书/微信即可），**不需要给你蓝湖管理员权限**。

### 2.1 必交项（P0 阻塞）

| # | 交付物 | 格式 | 用途 |
|---|--------|------|------|
| 1 | 关键页面切图 | PNG @2x/@3x 或 SVG | SOS 按钮、图标、空状态 |
| 2 | 色值表 | 表格 | `AppColors` |
| 3 | 字号 / 字重表 | 表格 | `AppTextStyles` |
| 4 | 间距 / 圆角规范 | 4/8/12/16… 或具体 px | `AppSpacing` |
| 5 | 全屏效果图 | PNG 整页 | 截图叠图对比 |
| 6 | 字体文件或名称 | ttf/otf 或系统字体名 | `pubspec.yaml` fonts |

### 2.2 建议交项（P1）

| # | 交付物 | 说明 |
|---|--------|------|
| 7 | 组件标注（按钮高度、图标尺寸） | 减少猜测量 |
| 8 | 交互说明（长按 3s、动效时长） | 逻辑实现 |
| 9 | 英文文案终稿 | 界面语言 en-US（见 MVP §3.2） |
| 10 | 深色模式（若有） | 第二套色值表 |

### 2.3 给设计的 Brief 模板（可复制）

```
【智能应急救援平台 - 用户端开发包需求】

我们为 Flutter 开发，无法使用蓝湖插件，请协助提供：

1. 以下页面导出切图（SVG 优先）：
   - 首页 SOS 按钮（默认 / 按下 / 禁用）
   - SOS 确认弹窗
   - SOS 状态页各状态插图（可选）
   - Tab 栏图标

2. 设计规范表（Excel/飞书表格）：
   - 主色、辅色、错误色、背景色、分割线色（HEX）
   - 标题/正文/辅助文字：字号、字重、行高、颜色
   - 常用间距、圆角、按钮高度

3. 每个页面一张 375×812（或设计稿宽度）PNG 效果图

4. 字体：若用自定义字体请给 ttf；否则注明 PingFang/SF Pro 等等效

5. 文案为英文（en-US），与 PRD 状态名一致

谢谢！
```

## 三、蓝湖无权限时的替代方案

| 方案 | 操作 | 适用 |
|------|------|------|
| **A. 开发包**（推荐） | 设计按 §二 打包发你 | 全项目 |
| **B. 截图叠图** | PNG 半透明叠在 Simulator/真机上调间距 | SOS 首页等关键页 |
| **C. 设计只读链接** | 向设计要蓝湖「分享链接」仅查看标注 | 有只读即可，不需插件 |
| **D. 导出标注 PDF** | 蓝湖导出标注手册 | 无链接时 |
| **E. MVP 降维** | Material 3 + 品牌主色 + 切图图标 | 工期极紧时 |
| **F. 蓝湖 Flutter 插件** | 有权限后再用，作辅助非依赖 | 后期优化 |

**不建议**：在完全没有标注和切图的情况下，凭感觉写 UI。

## 四、Flutter 工程落地：Design Token

在 Monorepo 的 `packages/rescue_mobile_ui`（或 `rescue_mobile_core`）集中定义，**禁止在页面写 magic number**。

### 4.1 目录建议

```
packages/rescue_mobile_ui/
├── lib/
│   ├── rescue_mobile_ui.dart
│   ├── theme/
│   │   ├── app_colors.dart
│   │   ├── app_text_styles.dart
│   │   ├── app_spacing.dart
│   │   └── app_theme.dart          # ThemeData 组装
│   ├── widgets/
│   │   ├── sos_button.dart
│   │   └── ...
│   └── assets/                     # 切图放各 app 或此处
└── pubspec.yaml
```

### 4.2 Token 示例（按设计表填写）

```dart
// app_colors.dart
abstract final class AppColors {
  static const Color primary = Color(0xFFE53935);   // 示例：来自设计色值表
  static const Color background = Color(0xFFF5F5F5);
  static const Color textPrimary = Color(0xFF212121);
}

// app_spacing.dart
abstract final class AppSpacing {
  static const double xs = 4;
  static const double sm = 8;
  static const double md = 16;
  static const double lg = 24;
}
```

### 4.3 屏幕适配

```yaml
# pubspec.yaml 依赖
dependencies:
  flutter_screenutil: ^5.9.0
```

设计稿宽度若为 375，在 `main.dart` 初始化 `ScreenUtilInit(designSize: Size(375, 812))`，宽度用 `.w`，字号用 `.sp`。

## 五、截图叠图调试法（关键页精调）

1. 设计提供页面 PNG（同分辨率）
2. 开发在页面 Stack 顶层放 `Opacity(opacity: 0.3, child: Image.asset('debug/home_overlay.png'))`
3. 真机调试对齐后 **删除或 `#ifdef DEBUG` 关闭**
4. 勿将 debug 叠图提交到 release 分支

**Cursor 提示词**：

> 根据附件首页效果图，在 rescue_user_app 用 AppColors/AppSpacing 实现 SOS 按钮，尺寸误差控制在 2dp 内。

## 六、按页面优先级实施

| 优先级 | 页面 | 还原策略 | App |
|--------|------|----------|-----|
| P0 | SOS 长按按钮 + 确认 | 切图 + Token + 叠图 | user |
| P0 | SOS 状态 / 时间线 | 以文案和状态色为主，插图可选 | user |
| P0 | 地图容器 | 地图 SDK 占满，自定义 pin 用切图 | user / worker |
| P1 | 登录注册 | Material + 品牌色 | user / worker |
| P1 | 设备列表 / 扫码 | 标准列表组件 + 图标 | user |
| P2 | 个人中心 / 设置 | 标准组件 | user |
| P2 | 工单列表 | 工具型 UI，弱视觉 | worker |

## 九、验收标准（替代「100% 还原」）

| 检查项 | 标准 |
|--------|------|
| 品牌色 | 与色值表 HEX 一致（允许 ±1 RGB） |
| SOS 按钮 | 可点击区域 ≥ 设计稿 44×44 dp |
| 字号层级 | 标题/正文/辅助三级与表一致 |
| 关键页 | 与全屏效果图对比，**肉眼无明显错位** |
| 功能 | P0 SOS 流程不受 UI 阻塞 |
