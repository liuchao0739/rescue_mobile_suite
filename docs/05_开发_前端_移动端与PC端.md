## 三、移动端（Flutter）

### 3.1 仓库结构（摘要）

详见 [04_开发_工程手册.md](./04_开发_工程手册.md) §五。

```
rescue_mobile_suite/
├── apps/rescue_user_app/
├── apps/rescue_worker_app/
└── packages/
    ├── rescue_mobile_core/
    ├── rescue_mobile_models/
    ├── rescue_mobile_map/
    └── rescue_mobile_ui/      ← Design Token、SOS 组件
```

### 3.2 环境

- Flutter SDK >= 3.9，`melos bootstrap`
- 真机调试：Android Studio 打开 `apps/rescue_user_app`
- 改共享包：Cursor 打开 `rescue_mobile_suite` 根目录

### 3.3 P0 页面（user_app，对齐 01 附录 B）

| 页面 | 功能要点 | 依赖 API |
|------|----------|----------|
| 登录/注册 | 手机/邮箱 | `/api/v1/auth/*` |
| 首页 | SOS 长按 3s | `POST /api/v1/sos` |
| SOS 确认 | 事故类型 | 同上 |
| SOS 状态 | 状态时间线 | `GET /api/v1/sos/{id}` |
| 设备列表 | 扫码绑定 | `/api/v1/devices/*` |
| 救援跟踪 | 地图、ETA | 第三阶段 |

### 3.4 P0 页面（worker_app）

| 页面 | 阶段 |
|------|------|
| 登录 | 三 |
| 可接工单 / 我的工单 | 三 |
| 接单、导航、状态更新 | 三 |

### 3.5 Cursor 提示词模板

```
在 rescue_mobile_suite/packages/rescue_mobile_ui 实现 SosButton，
遵循 03_设计_移动端设计交接指南.md 的 AppColors/AppSpacing，
文案 en-US，对接 POST /api/v1/sos（见 openapi.yaml）。
```

### 3.6 学习顺序（约 4～6 周）

| 周 | 内容 |
|----|------|
| 1 | Dart 基础 + 跑通 user_app 脚手架 |
| 2 | 网络层 `rescue_mobile_core` + 登录 |
| 3 | SOS 流程 UI + Mock API |
| 4 | 对接真 API + 真机验收 |
| 5～6 | 设备绑定、地图、worker_app |

## 四、PC 端（运营 Web + 调度大屏）

### 4.1 技术栈

- React 18 + TypeScript
- Ant Design Pro（表格、表单、RBAC）
- Mapbox GL（地图）
- WebSocket（SOS 实时弹窗，协议见 `docs/ws_events.md`）

### 4.2 路由规划

| 路径 | 页面 |
|------|------|
| `/login` | 登录 |
| `/dashboard` | 仪表盘 |
| `/sos` | SOS 中心列表 |
| `/sos/:id` | SOS 详情 |
| `/devices` | 设备管理 |
| `/sim` | SIM 管理 |
| `/dispatch` | 调度中心（三阶段） |
| `/dispatch-screen` | 调度大屏（三阶段） |

### 4.3 P0 功能（对齐 01 §六 第二阶段）

| 功能 | 说明 |
|------|------|
| 登录 + RBAC | Pro 权限框架 |
| SOS 中心 | 列表、筛选、详情 |
| GIS 地图 | SOS/设备图层 |
| 实时推送 | WebSocket `SOS_CREATED` |

### 4.4 MVP 设计策略

- **不必单独高保真**：Pro 默认布局 + 主色 + Logo
- 地图 pin、SOS 等级色块：03 中 Web 资产或简单 SVG
- 文案 en-US

### 4.5 Cursor 提示词模板

```
在 rescue_ops_web 用 Ant Design Pro 实现 SOS 列表页，
列字段与 openapi.yaml 中 SosEvent 一致，
英文界面，WebSocket 收到 SOS_CREATED 时刷新列表。
```

### 4.6 学习顺序（约 2～3 周）

| 周 | 内容 |
|----|------|
| 1 | TypeScript + Pro 脚手架跑起来 |
| 2 | SOS 列表/详情 + Mock |
| 3 | 地图层 + WebSocket + 真 API |
